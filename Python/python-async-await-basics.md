# Python async/await - 기다리는 동안 딴 일 하기
DB 조회, API 호출처럼 기다리는 작업이 많을 때 진가를 발휘한다. | 2026-06-18

### 개념
일반 코드는 한 작업이 끝나야 다음으로 넘어간다. DB 응답을 기다리는 동안 CPU가 늘게 된다.<br/>
async/await는 기다리는 동안 다른 작업을 처리하게 해준다. I/O가 많은 백엔드 서버에서 처리량을 크게 높일 수 있다.

### 동기 vs 비동기
동기(3초) - `A 1초` `B 1초` `C 1초`<br/>
비동기(1초) - `A 1초` `B 1초` `C 1초`<br/>
API 3개를 각각 1초씩 기다릴 때, 동기는 3초, 비동기는 동시에 날리면 1초에 끝난다.

> **asyncio.gather()가 핵심이다.** 여러 비동기 작업을 동시에 실행할 때 쓴다. 각각 await하면 순서대로 기다리므로 의미가 없다. 동시에 날릴 때는 gather로 묶어야 한다.<br/>
> **async 함수 안에서 일반 blocking 함수를 쓰면 안 된다.** time.sleep(), 일반 DB 드라이버 등 blocking 함수를 async 안에서 쓰면 전체 이벤트 루프가 멈춘다.
> 반드시 asyncio.sleep(), async 전용 라이브러리를 써야 된다.
