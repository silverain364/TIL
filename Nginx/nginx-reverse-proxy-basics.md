# Nginx - 앱 서버 앞에 세우는 관문
80포트로 들어온 요청을 8000번 앱으로 넘겨주는 리버스 프록시 | 2026-06-01

### 개념
Nginx는 웹 서버이자 리버스 프록시다. 클라이언트 80/443 포트로 Nginx에 접속하고, Nginx가 내부의 앱 서버(8000번 등)로 요청을 전달한다.<br/>
앱 서버를 직접 외부에 노출하지 않아도 되고, HTTPS 처리 및 로드밸런싱, 정적 파일 서빙 Nginx가 담당한다.

### Nginx가 하는 일
1. 리버스 프록시 : 외부 요청을 내부 앱 서버로 전달. 앱 포트 숨김.
2. HTTPS 처리 : SSL 인증서를 Nginx에서 관리. 앱은 HTTP로 통신
3. 로드밸런싱 : 여러 앱 서버에 요청을 분산.
4. 정적 파일 서빙 : 이미지, JS, CSS 등을 앱 서버 거치지 않고 직접 제공.

> **nginx -t 먼저, reload 나중에** 설정 파일에 오타가 있는데 reload하면 Nginx가 완전히 내려갈 수 있다. 반드시 nginx -t로 문법 확인 후 reload.<br/>
> **X-Real-IP 헤더 필수** 리버스 프록시 뒤에 있으면 앱 서버 입장에서 모든 요청이 Nginx IP로 보인다. proxy_set_header X-Real-IP로 실제 클라이언트 IP를 전달해야 로그나 Rate Limiting이 제대로 동작한다.
