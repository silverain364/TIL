# AWS S# - 파일은 서버에 저장하지 마라
이미지, 영상, 문서를 EC2 디스크에 올리면 서버가 재시작될 때 날아간다 | 2026-07-22

### 개념
S3(Simple Storage Service)는 AWS의 파일 저장소다. 이미지, 동영상, PDF, 백업 파일 등을 저장한다. EC2 디스트와 달리 서버가 꺼져도 파일이 사라지지 않고, 용량 제한 없이 저렴하게 무한 저장할 수 있다. 버킷이라는 단위로 파일을 관리한다.

### S3가 쓰이는 상황
`유저 프로필 이미지` - 업로드한 사진을 S3에 저장, URL을 DB에 기록.</br>
`문서 및 첨부파일` - 계약서, 보고서 등 업로드 파일 보관.</br>
`DB 백업` - 정기 백업 파일을 S3에 안전하게 저장.</br>
`정적 웹 호스팅` - React 빌드 결과물을 S3로 서빙 가능.</br>

> **Presigned URL이 실무 표준** - 파일을 백엔드에 거쳐 올리면 서버 메모리와 대역폭을 낭비한다. 클라이언트가 S3에 직접 올리고 백엔드는 URL만 받는 패턴이 훨씬 호율적이다.</br>

> **버킷을 public으로 열지 말 것** - S3버킷을 전체 공개하면 누구나 파일을 올리거나 지울 수 있다. IAM 권한과 버킷 정책으로 접근을 제한하고, 공개가 필요한 파일만 선택적으로 열어야 한다.
